One Line, One Chill — a single-sentence horror line, written by `main.ts` to `/output/entry.txt`.

## The line

> The night nurse logged my mother's last words at 3 AM, but my mother died in 2019, and the handwriting in the log is mine.

122 characters, one sentence. A hospice log, a mother dead since 2019, and handwriting the narrator never wrote — concrete, original, and the last word lands the scare.

## Run it

```sh
node main.ts
```

It validates the line (1–200 characters, exactly one sentence, single line), writes it to `/output/entry.txt`, then reads it back and re-validates it.
